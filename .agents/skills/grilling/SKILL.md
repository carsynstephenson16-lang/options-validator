---
name: grilling
description: Interview the user relentlessly about a plan, design, or conclusion to find where it breaks. Use when the user wants a plan stress-tested before building, or asks for adversarial review in any phrasing — 'be harsh', 'be brutally honest', 'unbiased critique', 'attack this', 'poke holes', 'play devil's advocate', 'tell me why this is wrong', 'show me how this could be lying' — as well as explicit 'grill' phrasing. Default to firing when the request is for criticism rather than confirmation.
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions one at a time, waiting for feedback on each question before continuing. Asking multiple questions at once is bewildering.

If a question can be answered by exploring the codebase, explore the codebase instead.
