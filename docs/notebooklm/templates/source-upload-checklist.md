# NotebookLM Source Upload Checklist

Use this before adding sources to NotebookLM. NotebookLM is a reading and
synthesis aid; it is not a data source, ledger, or authority by itself.

## Source Set

- File or URL:
- Author / publisher:
- Publication date:
- Version:
- Why this source belongs in the project:
- Whether the source includes paid or proprietary data:

## Exclusions

- Do not upload secrets, credentials, account identifiers, or broker statements.
- Do not upload post-in-sample market data unless the OOS reveal gate permits it.
- Do not treat generated summaries as evidence without checking the source text.

## Source Questions

- What claim can this source support?
- What claim can it not support?
- What assumptions does it make about options fills, liquidity, costs, or risk?
- Does it conflict with the repository guardrails?
